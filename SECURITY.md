# Security policy

Please do not disclose suspected vulnerabilities in a public issue. Use
[GitHub's private vulnerability reporting](https://github.com/lfarrand/aWOT/security/advisories/new)
and include a minimal reproducer, affected version or commit, and expected impact.

Security fixes are made on the default branch. This fork is maintained primarily
for the TEG firmware, so users should pin an exact commit and review `PATCHES.md`
before deploying it in a safety- or availability-sensitive application.
